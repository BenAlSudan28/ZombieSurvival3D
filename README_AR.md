# Zombie Survival 3D — نسخة أولية

لعبة أندرويد تجريبية ثلاثية الأبعاد باستخدام Kotlin وOpenGL ES، مع بناء APK عبر GitHub Actions.

## طريقة البناء من الهاتف
1. أنشئ مستودعًا جديدًا على GitHub باسم `ZombieSurvival3D`.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع، وليس المجلد الخارجي نفسه.
3. افتح تبويب Actions واسمح بتشغيل Actions إذا طُلب منك.
4. اختر `Build Zombie Survival 3D APK` ثم `Run workflow`، أو انتظر البناء الذي يبدأ بعد الرفع.
5. افتح عملية البناء الناجحة في أسفل الصفحة، ثم نزّل `ZombieSurvival3D-APK` من قسم Artifacts.
6. فك ضغط الملف الناتج وثبّت `app-debug.apk` على هاتف أندرويد.

## التحكم
- `◀ MOVE` و`MOVE ▶`: تحريك اللاعب.
- `✦ SHOOT`: إطلاق النار.
- اقتل الزومبي لتحصل على 10 نقاط لكل واحد. إذا وصلت الصحة إلى صفر تنتهي الجولة.

هذه نسخة أولية قابلة للتطوير؛ الرسوميات مجسّمات ثلاثية الأبعاد بسيطة وليست لعبة AAA مكتملة.
